# Bus-Spotting
Bus Spotting is an Android App designed for bus spotters to take or upload pictures of busses, organised by bus models for operators all over the uk.

This app is open sorce and i encourage you to fork off this to add whatever you like, weather its other transport, adding live bus times or anything else! all i ask is that you mention me by my github username in the README.md file.

Installation
To install Bus Spotting, download the latest version from the [releases page](https://github.com/MrTecHead/Bus-Spotting/releases) and open the APK file. You may be prompted to manage permissions in your settings app to allow apps from unknown sources.

This app uses the Bustimes.org API.
